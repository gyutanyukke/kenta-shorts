利用規約・プライバシーポリシー

制定日：2026年10月10日

「けんた食堂 ショート動画検索」（以下「本サイト」）は、YouTubeチャンネル「けんた食堂（@oi_ken）」のショート動画を、タイトルやカテゴリで探しやすくするための非公式のファンサイトです。YouTube、Google、けんた食堂およびその運営者とは一切関係がなく、承認や提携を受けたものではありません。

利用規約

1. YouTube利用規約への同意

本サイトはYouTube APIサービスを利用しています。本サイトを利用することにより、利用者はYouTube利用規約に拘束されることに同意したものとみなします。

2. 掲載している情報

  • 動画のタイトル、概要、サムネイル画像、公開日は、YouTube Data API を通じてYouTubeから取得したもので、出典はYouTubeです。
  • これらの著作権その他の権利は、動画の投稿者に帰属します。本サイトは内容を改変せずに表示し、再生はYouTube上で行います。
  • 情報は1日1回自動で更新します。YouTube上で削除・非公開になった動画は、最長でも30日以内に本サイトからも削除されます。
  • カテゴリは、タイトル等から本サイトが自動で推定したもので、投稿者が設定したものではありません。誤っている場合があります。

3. 免責

本サイトの情報の正確性・完全性は保証しません。本サイトの利用、またはリンク先の利用によって生じた損害について、運営者は責任を負いません。本サイトは予告なく内容の変更や公開の停止をすることがあります。

4. 掲載停止のご要望

投稿者ご本人など権利をお持ちの方から掲載停止のご要望があった場合は、速やかに対応します。下記の連絡先までご連絡ください。

プライバシーポリシー

1. 取得する情報

本サイトには会員登録やログイン、入力フォームはなく、氏名・メールアドレスなどの個人情報は取得しません。検索語やカテゴリの選択は利用者の端末内だけで処理され、運営者のサーバーには送信されません。

2. 端末に保存する情報

本規約に同意したことを記録するため、利用者のブラウザ（localStorage）に同意の有無だけを保存します。また、通信できないときでも表示できるよう、本サイトの画面とデータをブラウザに一時保存します。これらはブラウザの設定から削除できます。

3. 第三者のサービス

  • YouTube API サービス：動画情報の取得に利用しています。YouTubeおよびGoogleによる情報の取り扱いについては、Googleプライバシーポリシーをご覧ください。
  • サムネイル画像：YouTubeのサーバー（i.ytimg.com）から直接読み込むため、閲覧時に利用者のIPアドレス等がGoogleに送信されます。
  • ホスティング（Vercel）：本サイトはVercel, Inc.のサービス上で公開しており、配信のためにアクセスログ（IPアドレス、ブラウザの種類、閲覧日時など）が記録されます。詳しくはVercelのプライバシーポリシーをご覧ください。
  • 動画を開くと YouTube に移動します。移動先での情報の取り扱いは YouTube および Google の規約に従います。

本サイトは広告やアクセス解析ツールを利用していません。

4. YouTubeへのアクセス許可の取り消し

本サイトは利用者のYouTubeアカウントへのアクセス許可を求めません。他のサービスで許可を与えている場合は、Googleアカウントのセキュリティ設定から取り消せます。

5. 改定

本ポリシーは必要に応じて改定し、このページで公開します。
