# けんた食堂 ショート動画検索

YouTubeチャンネル「けんた食堂（@oi_ken）」のショート動画をタイトルで検索するスマホ向けWebアプリです。
毎日13時（日本時間）にGitHub Actionsが一覧を取り直し、GitHub Pagesで公開します。サーバー代・API代はかかりません。

## フォルダ構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（検索・一覧・詳細ポップアップ） |
| `data/videos.json` | 動画一覧。毎日自動で更新される（手で編集しない） |
| `data/synonyms.json` | 同義語辞書。「アジ」→「鯵」「鰺」のような対応を自由に追加できる |
| `scripts/fetch-videos.mjs` | YouTube Data API から一覧を取るスクリプト |
| `.github/workflows/update.yml` | 毎日13時の自動実行と公開の設定 |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面に追加して使うための設定 |

## 初回セットアップ（約20分）

### 1. YouTube Data API のキーを作る

1. [Google Cloud コンソール](https://console.cloud.google.com/) にGoogleアカウントでログインし、新しいプロジェクトを作る
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を検索して「有効にする」
3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
4. 作成したキーの「APIの制限」で **YouTube Data API v3 だけ** に絞って保存
5. キー（`AIza…` で始まる文字列）を控えておく。料金は発生しません（1日の無料枠10,000に対し、このアプリの使用量は1日数ユニット）

### 2. GitHub にリポジトリを作る

1. GitHub で新しいリポジトリを作る（例：`oiken-shorts`）。無料プランでGitHub Pagesを使うには **Public** にする必要があります
   - 本サイトは一般公開・検索エンジン掲載を前提にしています。自分専用に戻したい場合は `robots.txt` を `Disallow: /` にし、`index.html` に `<meta name="robots" content="noindex">` を足してください
2. このフォルダの中身をすべてアップロード（`.github` フォルダも忘れずに。ブラウザからなら「Add file」→「Upload files」にフォルダごとドラッグ）

### 3. キーを登録して公開設定をする

1. リポジトリの **Settings → Secrets and variables → Actions → New repository secret**
   - Name：`YT_API_KEY`
   - Secret：手順1で控えたキー
2. **Settings → Pages** の「Source」を **GitHub Actions** にする

### 4. 初回の取得を実行する

1. **Actions** タブ →「ショート一覧を更新して公開」→「Run workflow」
2. 「全件取り直す」にチェックを入れて実行（1〜2分）
3. 完了するとアプリのURL（`https://<ユーザー名>.github.io/oiken-shorts/`）が表示されます

以後は毎日13時に自動で新着が追加されます。日曜日は全件取り直して、削除・非公開・タイトル変更も反映します。

### 5. スマホのホーム画面に追加する

- **iPhone**：SafariでURLを開く → 共有ボタン →「ホーム画面に追加」
- **Android**：ChromeでURLを開く → メニュー →「ホーム画面に追加」

## 使い方

- 検索窓に入力すると、タイトルにその文字を含む動画にその場で絞り込まれます
  - ひらがな・カタカナ・全角・半角の違いは無視します（「あじ」でも「アジ」がヒット）
  - 同義語辞書にある語は漢字表記もヒットします（「アジ」で「鯵」も）
  - スペース区切りで複数語のAND検索（例：「アジ フライ」）
- 動画をタップすると公開日・URL・概要が表示され、「YouTubeで開く」で再生できます
- 検索語はURLに残るので（`?q=アジ`）、よく使う検索はブックマークできます

## カテゴリで絞り込む

検索窓の下のボタンで、白ごはん.com と同じ8つの大分類（ごはん／汁もの／おかず／時短や作り置き／めんと鍋もの／ごはんのお供や保存食／下ごしらえや基本／おやつ）から絞り込めます。大分類を押すと小分類が出ます。文字検索と同時に使えます。

- 判定はタイトルとハッシュタグから自動で行います。料理の種類が分からないときは概要の冒頭（材料の手前まで）も見ます
- それでも分からない動画は「未分類」に入ります
- 毎日の自動実行のログ（Actions → 実行結果 →「YouTube から取得」）に、未分類の動画が一覧で出ます

### 分類を直したいとき

| やりたいこと | 編集するファイル |
| --- | --- |
| キーワードを足して、同じ種類の動画をまとめて分類したい | `data/categories.json` の該当カテゴリの `keywords` に語を追加 |
| 誤って分類される語がある（例：「フライパン」が「パン」に） | 同じカテゴリの `exclude` に語を追加 |
| 特定の動画だけ分類を指定したい | `data/category-overrides.json` に `"動画ID": ["okazu/niku"]` の形で追加 |

GitHub上でファイルを開き、鉛筆アイコンで編集して「Commit changes」を押せば、Vercelに自動で反映されます（動画の再取得は不要）。

## 一般公開にあたって

- 非公式のファンサイトであること、出典がYouTubeであることを画面下部とポップアップに表示しています
- 初回アクセス時に、利用規約・プライバシーポリシー・YouTube利用規約への同意を求めます（YouTube API の開発者ポリシーで必要なため）
- 利用規約・プライバシーポリシーは `policy.html` です
- 広告は付けないでください（YouTube API の規約と Vercel 無料プランの条件のため）

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 「未取得」のまま | 手順4を実行したか。Actions タブで赤い×が出ていればログを確認 |
| Actions が `YT_API_KEY が設定されていません` で失敗 | 手順3のSecret名が `YT_API_KEY` になっているか |
| `403 forbidden` / `quotaExceeded` | APIが有効か、キーの制限がYouTube Data API v3になっているか |
| 13時ちょうどに更新されない | GitHubの混雑で数分〜数十分遅れるのは仕様です |
| 自動更新が止まった | 長期間リポジトリに動きがないとGitHubが定期実行を停止することがあります。Actions タブで再度有効化してください |

## 補足：ショート動画の判定方法

YouTube APIには「ショートかどうか」の公式な項目がないため、YouTubeが自動で作るショート専用の再生リスト（チャンネルIDの `UC` を `UUSH` に置き換えたもの）を使っています。
これが使えなくなった場合は、自動で「全動画のうち3分以下」の判定に切り替わります。
